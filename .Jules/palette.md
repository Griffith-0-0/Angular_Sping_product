## 2026-03-07 - Semantic Navigation and Route Feedback
**Learning:** Semantic navigation using `<a>` tags and providing visual feedback for the active route significantly improves both accessibility and user experience. In Angular, `routerLinkActive` and `ariaCurrentWhenActive` are essential for this.
**Action:** Always use `<nav>`, `<a>` tags for navigation, and ensure active states are visually and programmatically represented.
