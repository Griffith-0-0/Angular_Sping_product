## 2026-03-18 - [Enhancing Navigation Accessibility and Visuals]
**Learning:** In this Angular standalone setup, converting generic `div` elements into semantic `<a>` tags within a `<nav>` landmark significantly improves accessibility and keyboard navigation. Using `routerLinkActive` and `ariaCurrentWhenActive="page"` provides essential visual and programmatic feedback to all users.
**Action:** Always prefer semantic elements and ARIA attributes for core navigation structures to ensure a robust and accessible user experience.
