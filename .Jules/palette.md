## 2026-06-05 - Semantic Navigation and Route Feedback
**Learning:** Using semantic HTML (`<nav>`, `<a>`) combined with Angular's `RouterLinkActive` and `ariaCurrentWhenActive` provides a robust, accessible foundation for navigation that benefits both visual users and those using assistive technologies.
**Action:** Always prefer semantic navigation landmarks and explicit active state indicators (both visual and ARIA) for main app shells.
