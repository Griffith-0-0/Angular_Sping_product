## 2026-05-18 - Semantic Navigation with Visual & Programmatic Feedback
**Learning:** Using semantic <a> tags within a Bootstrap btn-group for navigation provides native browser behaviors like focus states and right-click support, while routerLinkActive and ariaCurrentWhenActive ensure both visual and programmatic accessibility for the current route.
**Action:** Always prefer semantic <a> tags for navigation and use ariaCurrentWhenActive="page" to satisfy screen reader requirements for active links.
