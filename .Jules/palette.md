
## 2026-06-06 - Accessible and Semantic Navigation
**Learning:** Replacing non-semantic `div` elements with semantic `<a>` tags and using `aria-current` (`ariaCurrentWhenActive="page"` in Angular) significantly improves the accessibility and predictability of the navigation experience. Grouping navigation items in a `btn-group` provides a cohesive and polished look.
**Action:** Always prefer semantic HTML and ARIA attributes for core navigation. Ensure active states are both visually and programmatically clear.
