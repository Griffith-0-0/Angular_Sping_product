## 2026-06-07 - Accessible Navigation with Semantic Landmarks
**Learning:** Using `<a>` tags with `routerLinkActive` and `ariaCurrentWhenActive="page"` provides much better screen reader support and user feedback than styled `<div>` elements. Wrapping the layout in `<header>` and `<main>` landmarks improves page structure.
**Action:** Always prefer semantic HTML and built-in Angular accessibility attributes for navigation components.
