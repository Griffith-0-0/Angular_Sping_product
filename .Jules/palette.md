## 2026-03-02 - [Semantic Navigation and Accessibility]
**Learning:** Using semantic HTML (e.g., `<a>` tags within a `<nav>` with `aria-label`) and providing visual feedback for active routes (e.g., `routerLinkActive`) significantly improves the accessibility and intuitiveness of navigation menus. Wrapping main content in a `<main>` landmark also helps screen reader users navigate the page structure more effectively.
**Action:** Always prefer semantic tags and ARIA labels for navigation elements and ensure clear visual and programmatic indicators for the current page.
