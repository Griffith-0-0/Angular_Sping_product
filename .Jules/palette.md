## 2026-03-08 - [Semantic Navigation and Active States]
**Learning:** Using semantic `<a>` tags with `ariaCurrentWhenActive="page"` and `routerLinkActive` in Angular standalone components provides both visual and screen-reader accessibility with minimal code.
**Action:** Always prefer semantic `<nav>` and `<a>` elements over `<div>` for navigation, and ensure `RouterLinkActive` is imported in standalone components to enable active styling.
