## 2026-07-25 - Semantic Navigation & Router Link Active State Bindings
**Learning:** In modern Angular standalone applications, using non-semantic element wrappers (such as `<div>` with `routerLink` directives) leads to severe accessibility gaps because they lack native keyboard focus, tab indexing, and interactive roles. Utilizing standard `<a>` elements within a `<nav>` is essential. To toggle active button styles cleanly without custom styling classes, exporting `routerLinkActive` to a template reference variable allows dynamic, conflict-free class binding (`[class.btn-primary]="rla.isActive"`, `[class.btn-outline-primary]="!rla.isActive"`). Furthermore, screen-readers must be made aware of the active page through setting `[attr.aria-current]="rla.isActive ? 'page' : null"`.
**Action:** Always prefer semantic `<a>` tags for router navigation inside a `<nav>` landmark, and bind class active/inactive variants and ARIA attributes dynamically via exported `routerLinkActive` reference variables.
