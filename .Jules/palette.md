## 2026-10-22 - Semantic Navigation & Active Route State
**Learning:** Replacing non-semantic `<div>` router links with semantic `<a>` links and `routerLinkActive` bindings ensures keyboard accessibility and active state clarity for screen readers via `aria-current="page"`.
**Action:** Always convert custom interactive `<div>` controls to native semantic `<a>` or `<button>` elements with proper ARIA attributes.
