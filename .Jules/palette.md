## 2026-08-03 - [Semantic & Accessible Component Routing Navigation in Angular 20]
**Learning:** In modern Angular 20 applications utilizing standalone components, using div elements for route navigation completely breaks keyboard accessibility, tab indices, and screen reader announcements. When upgrading them to semantic 'a' elements styled as Bootstrap buttons, using the routerLinkActive directive is crucial. To avoid template-wide rendering shifts and active color contrast issues, export routerLinkActive as a template reference variable (e.g., #link="routerLinkActive") to bind Bootstrap's conditional styling classes ([class.btn-primary]="link.isActive" [class.btn-outline-primary]="!link.isActive"). Additionally, RouterLinkActive must be explicitly added to imports in the standalone parent component's class definition, and aria-current page mapping should use [attr.aria-current]="link.isActive ? 'page' : null" to prevent inconsistent screen reader behavior.
**Action:** Always verify parent component imports for directive resolution, use semantic link groups under a labeled <nav> landmark, and utilize template variables for conditional styling.
