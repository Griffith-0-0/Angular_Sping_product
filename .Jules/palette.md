## 2026-09-30 - Semantic Navigation Links & Active State ARIA Attributes
**Learning:** Replacing non-semantic `<div>` navigation with semantic `<a>` tags inside a Bootstrap `.btn-group` wrapper along with `aria-label` and `[attr.aria-current]` attributes provides keyboard accessibility and screen reader support without breaking visual styling.
**Action:** Always convert custom element click handlers or non-semantic router links to semantic anchor tags with explicit `aria-label` and `aria-current` bindings.
