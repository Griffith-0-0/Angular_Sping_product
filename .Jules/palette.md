## 2026-07-11 - Semantic Navigation with Active State Feedback
**Learning:** Using `routerLinkActive` with template reference variables (e.g., `#rla="routerLinkActive"`) allows for clean, declarative toggling of Bootstrap button variants (`btn-primary` vs `btn-outline-primary`) without custom CSS or complex component logic.
**Action:** Use this pattern for all navigation elements to provide immediate visual feedback and maintain design system consistency.
