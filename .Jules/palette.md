## 2026-08-08 - Accessible and Semantic Semantic Landmark Navigation in Angular 20
**Learning:** Using generic elements such as `div` for navigation links excludes assistive technologies and keyboard-only users. Furthermore, applying both active and inactive style classes directly to links without dynamic binding results in redundant/conflicting UI state. Combining semantic elements like `<nav>`, wrapping links in `.btn-group.shadow-sm` within a `<header>` landmark, utilizing Angular's `RouterLinkActive` directive with appropriate class binding, and adding `[attr.aria-current]` significantly enhances accessibility and UX.
**Action:** Always wrap application navigation structures in a `<nav>` with a descriptive `aria-label`, use semantic `<a>` tags with `RouterLinkActive`, dynamic class bindings (e.g., `[class.btn-primary]="rla.isActive"`), and `[attr.aria-current]` mapping to active state.
